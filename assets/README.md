# Your photo goes here

Add your portrait as **`anas.jpg`** in this `assets/` folder and the hero will
use it automatically. Until then, the site shows an "AA" monogram instead.

## How to add it (easiest — no tools needed)
1. Save your photo (e.g. the one from LinkedIn) to your computer.
2. Rename it to **`anas.jpg`**.
3. On GitHub: open this `assets/` folder → **Add file → Upload files** →
   drag `anas.jpg` in → **Commit** to the `gh-pages` branch (and the
   `claude/great-ritchie-4khmdd` branch).

Tips:
- A roughly square or portrait (4:5) image looks best; ~600×750px is plenty.
- `.jpg` is expected. To use a `.png` instead, name it `anas.jpg` anyway, or
  tell me and I'll switch the reference in `index.html`.
